# PawMate 宠伴到家 · 微信小程序 MVP

面向上门喂猫、铲屎和遛狗服务场景的原生微信小程序原型。当前版本使用本地模拟数据，覆盖用户发布需求、查看订单，以及服务者接单和完成服务报告的核心流程。

## 本地运行

1. 打开微信开发者工具，选择“导入项目”。
2. 目录选择本仓库根目录。
3. AppID 可先使用测试号；项目配置位于 `project.config.json`。
4. 编译后可在“我的”页面切换宠物主人/服务者身份体验完整流程。

## 当前功能

- 三种服务：上门喂猫、清理猫砂、遛狗
- 服务者展示与详情
- 宠物、时间、地址及任务需求填写
- 本地创建和保存订单
- 服务者接单、开始服务、提交服务报告
- 主人查看服务进度和报告
- 双角色切换与基础个人中心

## 后续正式化

接入微信登录、后端数据库、对象存储、地图定位、订阅消息、微信支付、实名认证和运营管理后台后，才可用于真实交易。
